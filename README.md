## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Deepthi-M555/deepthi-portfolio.git
cd deepthi-portfolio
npm install
```

### Run Locally

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

The production build is generated in `dist/`.
